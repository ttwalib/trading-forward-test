Live signals, costs and data health

The 5-minute engine runs on GitHub every 5 minutes in market hours with no AI in the loop: it seals each baseline-A breakout and each intraday library signal with the time and the real-time price at that moment. Slippage compares what a real order would have paid with the simulated fill, without placing any order.

Slippage (no orders)

Spread = half the bid/ask gap a market order pays. Drift = how far the price moved between the simulated fill and the quote, mostly from the delay. The model cost is what the simulation charges per side.

Machine learning (take-or-skip filter)

The model is only used live if, on days it never saw, the trades it picks beat taking every signal. PBO is the chance its best setting was just lucky; above 0.5 means "probably luck".
